# pi-current

[English](../../README.md) | 简体中文

**搜索网络，关注你的兴趣。**

pi-current 是一个 [Pi](https://github.com/earendil-works/pi) 扩展，通过对话搜索公开网页、导入 RSS/Atom，并阅读本地文章库。

## 搜索与阅读

让 Pi 搜索主题、读取 URL，或打开搜索结果：

- “搜索最近关于 local-first software 的文章。”
- “阅读第二条结果，解释它的主要观点。”

搜索结果附带来源链接。公开网页阅读支持 HTML、纯文本和 Markdown。

## 导入订阅源

Pi 可以导入你提供的 RSS 2.0 或 Atom 1.0 feed，也可以为当前阅读任务选择 feed：

- “从 https://example.org/feed.xml 导入 5 条内容。”

内置的 feed 导入功能获取订阅源并将条目保存到本地 library，保留来源提供的文章文本、摘要和链接。只有摘要的条目仍标为摘要，不会自动访问链接补全正文。重复导入同一 feed 会复用已有条目，并保留内容变化的版本。

导入结果会说明保存数量和具体的条目问题，包括跳过的内容。Feed 内容由发布者提供，导入并不代表它与网站上的完整文章一致。

## 阅读本地文章库

让 Pi 搜索已保存内容或打开文章：

- “在我的 library 中搜索城市设计。”
- “打开那篇已保存的文章。”

搜索结果显示简短的本地预览。在交互式 Pi 中打开文章后，可以在本地阅读器中滚动阅读保存的文本。只有摘要的条目显示摘要和原文链接。正文不进入模型可见的工具结果，阅读器用于你直接阅读。没有交互式 UI 时，Pi 返回已保存条目的引用，不会打开阅读器。

Library 搜索和阅读支持离线使用。删除条目时，明确指定 `Delete saved item ITEM_ID`。

外部 source module 加载已移除。早期集成保存的文章仍可在本地 library 中使用。

## 后续方向

下一步是根据当前阅读兴趣选择来源、检索和排序文章。默认来源池与检索排序仍属于计划；目前提供网页访问、feed 导入和本地阅读。
