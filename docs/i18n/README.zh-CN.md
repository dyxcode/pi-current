# pi-current

[English](../../README.md) | 简体中文

**搜索网络，关注你的兴趣。**

pi-current 是一个 [Pi](https://github.com/earendil-works/pi) 扩展，通过对话搜索公开网页、从 feeds 发现文章，并阅读本地文章库。

## 搜索与阅读

让 Pi 搜索主题、读取 URL，或打开搜索结果：

- “搜索最近关于 local-first software 的文章。”
- “阅读第二条结果，解释它的主要观点。”

搜索结果附带来源链接。公开网页阅读支持 HTML、纯文本和 Markdown。

## 找些文章读

可以请求一份 mixed reading list，也可以指定主题：

- “找五篇文章，科技、人文和日常生活都看一些。”
- “找几篇关于城市生活与孤独的文章。”

Pi 从启用来源的当前 feed 条目中选择文章，并将选中内容保存到 library。泛读会交替选择不同来源；主题请求根据标题和摘要中的词语或短语匹配，优先考虑标题匹配。搜索范围是当前 feed 条目，不是各网站的完整历史文章库。

本地阅读 cards 按顺序显示结果，包含来源、可用的发布日期，以及主题请求匹配到的词语。接着说“打开第二篇”即可阅读已保存的文本。只有摘要的条目显示摘要与原文链接。部分来源失败时，仍会显示已经保存的结果和具体来源问题。

## 选择来源

在 Pi 中输入 `/source`，可以添加 feed、启用或禁用来源，以及从列表中移除来源。修改会自动保存。添加时输入 RSS/Atom URL 和显示名称；内容在你请求阅读发现时获取。

默认来源是 [MIT Research](https://news.mit.edu/rss)、[JSTOR Daily](https://daily.jstor.org/) 和 [Psyche](https://psyche.co/)，分别覆盖研究与科技、人文和日常心理阅读。移除来源会保留 library 中已保存的文章。

## 导入订阅源

Pi 可以导入你提供的 RSS 2.0 或 Atom 1.0 feed，也可以为当前阅读任务选择 feed：

- “从 https://example.org/feed.xml 导入 5 条内容。”

内置的 feed 导入功能获取订阅源并将条目保存到本地 library，保留来源提供的文章文本、摘要和链接。只有摘要的条目仍标为摘要，不会自动访问链接补全正文。重复导入同一 feed 会复用已有条目，并保留内容变化的版本。

导入结果会说明保存数量和具体的条目问题，包括跳过的内容。Feed 内容由发布者提供，导入并不代表它与网站上的完整文章一致。

## 阅读本地文章库

让 Pi 搜索已保存内容或打开文章：

- “在我的 library 中搜索城市设计。”
- “打开那篇已保存的文章。”

搜索结果显示简短的本地预览。在交互式 Pi 中打开文章后，可以在本地阅读器中滚动阅读保存的文本。只有摘要的条目显示摘要和原文链接。正文不进入模型可见的工具结果，阅读器用于你直接阅读。没有交互式 UI 时，Pi 返回已保存条目的引用，不会打开阅读器。

Library 搜索和阅读支持离线使用。删除条目时，明确指定 `Delete saved item ITEM_ID`。

外部 source module 加载已移除。早期集成保存的文章仍可在本地 library 中使用。

## 后续方向

目前通过标题／摘要匹配和来源交替完成阅读发现。定时获取与根据阅读反馈学习偏好属于后续方向。
