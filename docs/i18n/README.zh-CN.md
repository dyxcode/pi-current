# pi-current

[English](../../README.md) | 简体中文

**搜索网络，关注你的兴趣。**

pi-current 是一个 [Pi](https://github.com/earendil-works/pi) 扩展，通过对话搜索公开网页、从 feeds 发现文章，并阅读本地文章库。

## 搜索与阅读

让 Pi 搜索主题、读取 URL，或打开搜索结果：

- “搜索最近关于 local-first software 的文章。”
- “阅读第二条结果，解释它的主要观点。”

搜索结果附带来源链接。公开网页阅读支持 HTML、纯文本和 Markdown。

## 找些文章读

可以请求一份 mixed reading list，也可以指定主题：

- “推荐今天值得读的文章。”
- “找五篇文章，科技、人文和日常生活都看一些。”
- “找几篇关于城市生活与孤独的文章。”

Pi 先将启用来源的当前 feed 条目准备到本地文章库，再默认推荐五篇。泛读会交替选择不同来源，在每个来源内优先选择近期条目；主题请求根据标题和摘要中的词语或短语匹配，优先考虑标题匹配。“今天的推荐”表示今天的阅读选择，不限定文章必须今天发布。候选来自当前 feed 文档，不是各网站的完整历史文章库。

本地阅读 cards 按顺序显示结果，包含来源、可用的发布日期，以及主题请求匹配到的词语。接着说“打开第二篇”即可阅读已保存的文本。只有摘要的条目显示摘要与原文链接。部分来源失败时，仍会显示可用结果和具体来源问题。更新失败的来源可以继续使用上一次成功准备的内容，并在来源问题中标明准备时间。

## 选择来源

通过对话让 Pi 查找并添加来源，例如：“帮我添加几个科技和人文阅读源”，或“订阅这个网站：https://example.org”。Pi 接受网站和 RSS/Atom URL。对于网站，它会查找页面声明的 feed 链接：只有一个时验证并添加；有多个时返回候选，由 agent 根据你的兴趣选择。页面未声明 feed 时，Pi 可以继续搜索明确的 feed URL。

新来源通过 feed 验证后保存为启用状态。推荐请求使用已经启用的来源。重复添加已有来源会保留其名称和启用状态。

输入 `/source` 查看来源名称、网址和启用状态，并启用或禁用来源。修改会自动保存，并更新后台准备。禁用后，后续准备和推荐会排除该来源，已保存的文章仍保留。重新启用即可继续关注。

默认来源是 [MIT Research](https://news.mit.edu/rss)、[JSTOR Daily](https://daily.jstor.org/) 和 [Psyche](https://psyche.co/)，分别覆盖研究与科技、人文和日常心理阅读。

## 提前准备文章

每次会话启动时，pi-current 在后台准备启用来源。推荐请求会先检查这些来源是否有更新，再选择文章；已经进行的准备会被共享。通过 `/source` 修改来源后，后台准备也会随之更新。Standalone Pi 闲置时不会轮询来源，关闭 Pi 后后台工作停止。

对于提供 ETag 或 Last-Modified 响应头的来源，系统使用条件 HTTP 请求检查更新。来源未变化时复用已经保存的准备结果，不再下载和解析 feed 正文；未提供这些响应头的来源则正常获取。已准备文章和 HTTP 验证信息会在 Pi 重启后保留。

准备过程获取每个来源当前的 RSS 2.0 或 Atom 1.0 文档，清理 feed 提供的 HTML，并保存有效条目。状态栏显示处理的文章数量与来源问题。内容不变的文章复用现有版本，内容变化时保留版本历史。成功获取空 feed 会清空该来源的当前候选；更新失败则保留上一次成功准备的内容。下一次推荐请求或会话启动时，可以再次尝试失败的来源。

来源提供的正文、摘要和链接保留其实际内容类型。系统不会自动访问文章链接补全正文，也不会在准备过程中生成模型摘要。文章保存在本地文章库，准备过程不会自动删除已保存文章。

## 阅读本地文章库

让 Pi 搜索已保存内容或打开文章：

- “在我的 library 中搜索城市设计。”
- “打开那篇已保存的文章。”

搜索结果显示简短的本地预览。在交互式 Pi 中打开文章后，可以在本地阅读器中滚动阅读保存的文本。只有摘要的条目显示摘要和原文链接。正文不进入模型可见的工具结果，阅读器用于你直接阅读。没有交互式 UI 时，Pi 返回已保存条目的引用，不会打开阅读器。

Library 搜索和阅读支持离线使用。删除条目时，明确指定 `Delete saved item ITEM_ID`。

外部 source module 加载已移除。早期集成保存的文章仍可在本地 library 中使用。
